# Práctica RA5 · a+b — Datos e información

## 1) Caso
- Sistema:Aplicación de ventas online
- Contexto:Una tienda digital recoge datos de clientes y pedidos para mejorar sus ventas y tomar decisiones comerciales

-El ingreso medio por compra es de aproximadamente 80 €

## 4) Diferencia
-Dato: Es un valor aislado, sin contexto ni interpretación (por ejemplo, “79,99 €”)
-Información: Es el resultado de procesar y analizar datos para darles significado útil (por ejemplo, “el precio medio de compra es 80 €”)

## 5) Ciclo del dato
- Captura: Se registran datos cuando el cliente realiza una compra en la app
- Almacenamiento: Los datos se guardan en una base de datos
- Procesamiento: Se organizan y estructuran (por ejemplo, ordenar por fechas o productos)
- Análisis: Se estudian patrones de compra y tendencias
- Uso: Se toman decisiones comerciales (ofertas, stock, marketing)
- Eliminación: Se borran o archivan datos antiguos según normativa
  
## 6) Aplicación
-Decisiones: Aumentar el stock de productos más vendidos
Crear ofertas personalizadas para clientes frecuentes
Ajustar precios según demanda
-Valor:
Transformar datos en información permite mejorar la eficiencia, aumentar ventas y tomar decisiones estratégicas basadas en evidencia

## 9) Problemas
-Problema 1: Datos erróneos (precios mal introducidos)
-Solución 1: Validación automática de datos
-Problema 2: Datos incompletos (falta de información del cliente)
-Solución 2: Limpieza y normalización de datos
